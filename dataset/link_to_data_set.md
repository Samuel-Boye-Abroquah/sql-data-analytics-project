## Prerequisite

This project queries three views — `dim_customers`, `dim_products`, `fact_sales` — plus two raw tables . All raw files are built by the [Data Warehousing project](https://github.com/Samuel-Boye-Abroquah/sql-data-warehouse-project); run that project's setup first, then run any script here against the resulting database.You will have all scripts there from Bronze>Silver>Gold
